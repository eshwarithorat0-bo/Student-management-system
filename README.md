# Student Management System

## 📌 Project Overview

The Student Management System is a beginner-friendly SQL database project created using MySQL.

The project is designed to manage student information, courses, enrollments, and marks using a relational database.

## 🎯 Objectives

- Store student information
- Manage courses
- Manage student enrollments
- Store student marks
- Retrieve useful student information using SQL queries
- Practice database concepts and SQL commands

## 🛠️ Technologies Used

- MySQL
- SQL
- GitHub

## 🗄️ Database Tables

The project contains the following tables:

1. **Student**
   - Stores student personal information

2. **Course**
   - Stores course details

3. **Enrollment**
   - Stores student course enrollment information

4. **Marks**
   - Stores subject-wise student marks

## 📊 Sample Data

The database contains sample information for students, courses, enrollments, and marks.

## ▶️ How to Run the Project

1. Install MySQL.
2. Open MySQL Workbench or MySQL Command Line Client.
3. Run `database.sql`.
4. Select the `Student_Management` database.
5. Run the queries from `queries.sql`.
